# Code of conduct

This project is small, and the software can control someone’s PC. Be careful with other people’s machines and with each other.

- Discuss the code and the behavior. Leave personal attacks out of issues, pull requests, and chat.
- Do not ask someone to test a change on a computer they do not control.
- Do not post tokens, `.env` files, screenshots of private chats, or other people’s files.
- Assume good intent when a report is unclear, and ask for the missing step.

Maintainers may edit or close comments, issues, and pull requests that break these points. For a conduct problem, use the same private contact as in [SECURITY.md](SECURITY.md).
