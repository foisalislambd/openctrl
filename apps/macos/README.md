# macOS

Same OpenCtrl agent as Windows. This folder is the Mac desktop: System Events for windows and named controls, CoreGraphics for clicks, zsh for `run_shell`.

```sh
sh run.sh
```

The window stores the bot token and API key in `data/openctrl.db`. An existing `.env` is copied once.

Grant Accessibility to the terminal that launches `run.sh`. The screen has to stay unlocked.
